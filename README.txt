# Lion Roar Mercantile — Website MVP

A responsive static MVP for Lion Roar Mercantile.

## Included
- Responsive homepage
- Services and sourcing countries
- Product request form
- WhatsApp order handoff
- Demo order tracking
- Contact/phone/WhatsApp CTAs
- Mobile navigation
- Supplied logo adapted for the header

## Run locally
Open `index.html` in a browser.

## Publish
Upload the whole folder to your hosting public web directory (often `public_html`).

## Important
This is a front-end MVP. The order form currently creates a local order ID and opens WhatsApp; it does not store orders in a secure online database. For production, connect the form to a backend/database and add an authenticated admin dashboard, payment gateway, SMS/email notifications, and real shipment tracking.
